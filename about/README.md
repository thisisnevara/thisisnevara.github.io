# Переводы раздела «О песне»

Оригинал описания берётся из YouTube автоматически. Переводы лежат здесь:

- `about/es/<адрес песни>.txt` — на испанском
- `about/en/<адрес песни>.txt` — на английском
- `about/ru/<адрес песни>.txt` — на русском (для песен, у которых страница испанская)

Адрес песни — как в адресе страницы (например, `parol`). Абзацы разделяются пустой строкой.
Если перевода нет, на странице показывается оригинал с пометкой «перевода пока нет».
Если описание на YouTube изменилось, перевод сам не обновится — поправьте файл.
